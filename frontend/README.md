# Library Book Management System

A full-stack Library Book Management System developed using React.js, Node.js, Express.js and MongoDB.

## Technologies Used

- React.js
- Axios
- Node.js
- Express.js
- MongoDB
- Mongoose

## Features

- Add new books
- Store book details in MongoDB
- React.js frontend
- Express.js REST API
- Mongoose Book schema
- Form validation
- Success message after adding a book

## Book Details

- Book Title
- Author Name
- ISBN
- Category
- Publication Year

## API Endpoint

POST /api/books
